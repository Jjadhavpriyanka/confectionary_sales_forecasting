# Profit Forecasting and Strategic Profitability Analysis
## Project Overview
This project applies data mining, exploratory data analysis, feature engineering, and machine learning techniques to develop a profit forecasting solution for a confectionery business. The objective was to transform raw sales data into meaningful insights and predictive models that support business decision-making.
The project demonstrates an end-to-end data mining workflow, from data preparation and analysis to model development and evaluation using Python.

## Project Objectives
1. Explore and understand business sales data
2. Identify data quality issues and prepare data for analysis
3. Perform EDA
4. Engineer predictive features from historical data
5. Develop and evaluate machine learning models
6. Generate forecasts to support business planning
7. Present findings through data visualisation

## Business Problem
The organisation required a data-driven solution to improve profitability across multiple UK regions.
Management wanted to understand:
1. Which regions generate the highest profit?
2. Which products contribute most to profitability?
3. Whether profit follows seasonal patterns?
4. How future profitability can be predicted?
5. Which operational decisions could increase revenue?

The objective was to transform historical sales data into actionable business insights and reliable forecasts.
